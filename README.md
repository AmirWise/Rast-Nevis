# راست‌نویس (RastNevis) — ویراستار هوشمند فارسی برای توییتر/X

افزونه‌ی متن‌باز، سبک و کاملاً محلی برای مرورگرهای مبتنی بر کرومیوم جهت **تشخیص خودکار، خطایابی و ویرایش هوشمند خط و زبان فارسی** در تایم‌لاین توییتر (X).

---

## 🌟 ویژگی‌های کلیدی

- **موتور چندلایه‌ی هوشمند تشخیص هکسره:** تمایز دقیق غلط‌های هکسره از افعال ربطی عامیانه («است») و معرفه‌سازهای محاوره‌ای بدون مثبت کاذب.
- **اصلاح خودکار نویسه‌های عربی:** جایگزینی خودکار «ي» و «ك» عربی با «ی» و «ک» فارسی و مدیریت «ة/ۀ».
- **مدیریت ساختاری نیم‌فاصله‌ها:** تفکیک هوشمند پیشوندهای «می/نمی» و پسوندهای «ها/تر/ترین» با رعایت قوانین حروف جدانویس فارسی (مانند ر، ز، د، و، ا).
- **غلط‌یاب املایی بومی:** شناسایی لغات پرغلط روزمره در زبان فارسی و توییتر.
- **زیرخط تعاملی و نشان روی توییت:** هایلایت تمیز کلمات نادرست به همراه نمایش پاپ‌آپ علت خطا، پیش‌نمایش واژه اصلاح‌شده، و امکان کپی متن تماماً ویرایش‌شده با یک کلیک.
- **۱۰۰٪ محلی و امن (Zero Data Collection):** تمام پردازش‌ها بدون اتصال به هیچ سرور خارجی و مستقیماً روی مرورگر شما انجام می‌شود.

## 🔍 معماری موتور هوشمند هکسره

«هکسره» (استفاده‌ی نادرست از «ه» به جای کسره‌ی اضافه یا بالعکس) یکی از رایج‌ترین خطاهای نوشتار فارسی در فضای مجازی است. راست‌نویس با پیاده‌سازی «خط لوله‌ی آزمون‌های نحوی» (Syntactic Pipeline)، چهار نقش ساختاری متفاوت حرف «ه» را تفکیک می‌کند:

```
                  ┌────────────────────────────────────────┐
                  │      واژه به «ه / ـه» ختم شده است      │
                  └───────────────────┬────────────────────┘
                                      │
            ┌─────────────────────────┴────────────────────────┐
            ▼                                                  ▼
[آزمون ۱: ه ذاتی یا مشتق؟]                             [آزمون ۲: فعل ربطی محاوره‌ای؟]
(خانه، پرنده، پروژه، توسعه، دوستانه)                   (هوا سرده = سرد است -> درست است)
        │                                                      │
    [مصونیت]                                               [مصونیت]
                                                               │
                                ┌──────────────────────────────┴─────────────────┐
                                ▼                                                ▼
                     [آزمون ۳: معرفه‌ساز عامیانه؟]                    [آزمون ۴: شکار قطعی هکسره]
                     (این پسره رفت -> درست است)                       (کتابه علی، توییته تستی)
                                │                                                │
                            [مصونیت]                                       [خطای هکسره!]
```

### ۱. هکسره مستقیم (کسره اضافه که اشتباهاً «ه» نوشته شده)
- **ترکیب اسم + ضمیر:** `کتابه من` ← `کتاب من` | `عکسه تو` ← `عکس تو` | `دستوره ما` ← `دستور ما`
- **ترکیب اسم + صفت بیانی/نسبی:** `توییته تستی` ← `توییت تستی` | `کتابه خوب` ← `کتاب خوب` | `حاله روحی` ← `حال روحی`
- **زنجیره اضافه غلط:** `اکستنشنه شناساییه غلطه هسکره` ← `اکستنشن شناسایی غلط هسکره`
- **ترکیب‌های اضافی در شبه‌حروف‌اضافه:** `برایه` ← `برای` | `به خاطره` ← `به خاطر` | `سمته` ← `سمت`

### ۲. هکسره معکوس (کسره به جای «ه»)
- کسره‌ی پایانی که بدون مضاف‌الیه یا در پایان جمله آمده باشد: `اسم پسرش آرادِ` ← `آراده` | `این روش درستِ` ← `درسته`
- رفع باگ‌های حریصانه روی واژگان مختوم به ه: `هسکرهِ` ← `هسکره`

### ۳. مصونیت واژگان درست و صفر بودن خطای مثبت کاذب (Zero False Positives)
- **واژگان دارای ه ذاتی:** `قرمه سبزی`، `جامعه مدنی`، `رابطه عمومی`، `هندوانه`، `نقاره`، `پیاله`
- **وام‌واژه‌ها و اسامی روزمره:** `پروژه جدید`، `تجربه تلخ`، `انگیزه بالا`، `توسعه فردی`، `حافظه گوشی`
- **مشتقات زاینده با پسوند -انه:** `محرمانه`، `دوستانه`، `خائنانه`، `سالانه`، `صادقانه`
- **اوزان عربی مُفاعَله و تَفعِله:** `مصاحبه`، `معامله`، `مکالمه`، `توصیه`، `تصفیه`، `تسویه`
- **فعل ربطی اسنادی («است»):** `هوا سرده`، `کارش خوبه داداش`، `این روش درسته، ولی...`
- **معرفه‌ساز عامیانه:** `این پسره خیلی بی‌ادبه`، `این خانومه محل سگ به کسی نمی‌ذاره`

## 📋 جدول دسته‌بندی خطاهای ویرایشی

| دسته | سطح خطا | نمونه اشتباه | شکل درست |
|:---|:---:|:---|:---|
| **هکسره** | خطا (Error) | `توییته تستی` / `کتابه علی` | `توییت تستی` / `کتاب علی` |
| **هکسره معکوس** | خطا (Error) | `اسم پسرش آرادِ` | `اسم پسرش آراده` |
| **نویسه‌های عربی** | خطا (Error) | `نميدونم` / `بانك` | `نمیدونم` / `بانک` |
| **غلط املایی** | خطا (Error) | `اسفاده` / `خاهش` / `مشگل` | `استفاده` / `خواهش` / `مشکل` |
| **نیم‌فاصله فعل** | هشدار (Warning) | `میخوام` / `نمیدانم` | `می‌خوام` / `نمی‌دانم` |
| **نیم‌فاصله پسوند** | هشدار (Warning) | `بچه ها` / `خوب تر` | `بچه‌ها` / `خوب‌تر` |
| **تنوین نصب** | پیشنهاد (Hint) | `واقعا` / `احتمالا` | `واقعاً` / `احتمالاً` |
| **تکرار کاراکتر** | پیشنهاد (Hint) | `عالییییی` | `عالی` |

## 🚀 راهنمای نصب و استفاده

### نصب بر روی مرورگرهای مبتنی بر Chromium (Chrome, Edge, Brave, Opera, Arc)

1. پوشه‌ی افزونه را دانلود یا کلون کنید:
   ```bash
   git clone https://github.com/your-username/rastnevis.git
   ```
2. مرورگر خود را باز کرده و به بخش افزونه‌ها بروید:
   - در کروم و بریو: `chrome://extensions`
   - در مایکروسافت اج: `edge://extensions`
3. گزینه‌ی **حالت توسعه‌دهنده (Developer mode)** را در گوشه‌ی بالا فعال کنید.
4. روی دکمه‌ی **بارگذاری بازشده (Load unpacked)** کلیک کنید.
5. پوشه‌ی `extension` را انتخاب کنید.
6. وارد سایت [X (Twitter)](https://x.com) شوید؛ افزونه بلافاصله توییت‌ها را تحلیل و ویرایش‌ها را نمایش می‌دهد.
